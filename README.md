# README: Tic Tac Toe

A Tic Tac Toe game played on the command line where two human players can play against each other, and the board is displayed between turns.

This <a href="https://www.theodinproject.com/lessons/ruby-tic-tac-toe" target="_blank">Tic Tac Toe</a> assignment is part of the <a href="https://www.theodinproject.com/paths/full-stack-ruby-on-rails" target="_blank">Ruby on Rails</a> curriculum.

The <a href="https://www.theodinproject.com/about" target="_blank">Odin Project</a> provides a high quality coding education maintained by an open source community.

## Assignment: Bubble Sort

Build a tic-tac-toe game on the command line where two human players can play against each other and the board is displayed in between turns.

1. Think about how you would set up the different elements within the game… What should be a class? Instance variable? Method? A few minutes of thought can save you from wasting an hour of coding.
2. Build your game, taking care to not share information between classes any more than you have to.
